# MapDrawUndo

マップに描いた **自分の線** を `Ctrl+Z`(Mac は `Cmd+Z` も)で 1 本ずつ取り消します。消しゴムで消した跡も 1 本の線として取り消せます。

- マップ画面を開いているときだけ効きます。描いている途中は効きません
- マルチプレイでは、取り消しが仲間の画面にも反映されます(**仲間もこの Mod を入れている場合だけ**。入れていない仲間の画面には線が残ります)
- 他の人の線は消せません(ゲーム標準の「消去」ボタンと同じく、自分の線だけが対象)

## 仕組み

ゲームは線 1 本を `Line2D` 1 つとして、プレイヤーごとの `SubViewport` に描いています(`NMapDrawings`)。
取り消しはその最後の `Line2D` を消し、専用のメッセージ `zMapDrawUndoMessage` で仲間に「最後の線を 1 本消した」と伝えます。
線の同期は取りこぼしのある通信なので、取り消しは直前の線の送信が終わる 0.15 秒後に送り、
仲間側でまだ描きかけの線に取り消しが届いた場合は描き終わってから消します。

実機では未確認です(クラウドにゲームが無いため)。ゲームの版が変わってクラス構成が違う場合はパッチが当たりません。
