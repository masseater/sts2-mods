# PeerSelectionHud

マルチプレイで、仲間が **今何をしているか** を画面の左に出します。一人プレイでは何も出ません。

仲間ごとに次を表示します。

- 今いる画面(マップ、報酬画面、カード選択中、デッキ確認、ポーズメニューなど)
- カーソルを合わせている(または使おうとしている)カード・レリック・ポーションの名前
- マップで投票している行き先(段と列)

表示に使うのはゲームがもともと仲間と同期しているデータだけなので、**仲間がこの Mod を入れていなくても動きます**。
ゲームが同期していない情報(報酬画面でどの報酬にカーソルを合わせているか、イベントの選択肢など)は出せません。

## 仕組み

`RunManager.Instance` の `PeerInputSynchronizer`(画面・対象選択中か)、`HoveredModelTracker`(カーソルを合わせているもの)、
`MapSelectionSynchronizer`(投票)のイベントを購読して、変化があったときだけ文字を書き換えます。
表示はゲームの画面より手前の `CanvasLayer` に置き、クリックは奥へ素通しします。

実機では未確認です(クラウドにゲームが無いため)。
